# 教学功能规则与验证记录

更新日期：2026-09-22。

## 角色和课程

### 首页功能入口

首页三张功能卡片均提供可用链接。作业中心按身份、课程和状态展示作业，支持分页；成绩反馈中心展示本人（教师为自己课程）的提交、成绩与评语，保留历史版本和退课记录。个人页及侧栏提供同样入口。

新增 8 项自动化测试覆盖登录要求、角色数据隔离、提交状态、归档、筛选、分页、0 分展示、历史版本和入口。全量共 30 项测试通过。本轮没有模型变更，无需数据库迁移。

- 教师只能编辑、归档、恢复自己的课程，管理本课程的作业、资料和评分。
- 学生可以自由选课；选退课通过带 CSRF 校验的 POST 表单完成。
- 未选课者只能查看课程公开介绍，不能访问课程作业或下载资料。
- 课程归档后保留成员、作业、资料、提交和成绩；停止新增选课、内容修改、提交与评分。教师恢复课程后可继续操作。
- 学生退出课程不删除提交或成绩；学生仍可在个人页查看自己的历史提交、成绩及附件。重新选课不会重置已有提交或评分。
- 课程使用归档代替删除。有学生提交的作业禁止直接删除；无提交的作业可以由课程教师删除。
- 教师身份仍可在实验注册页面选择；本次未增加教师审核或邀请码。

## 作业与提交

1. 教师发布作业并设置未来的截止时间。已有作业不可转移到其他课程。
2. 时间统一按 `Asia/Shanghai`（北京时间）展示和输入。截止时刻起禁止提交或撤回，不只隐藏按钮，后台也校验。
3. 每名学生、每份作业只有一份有效提交；提交人从登录账号获取，作业从 URL 编号获取。
4. 截止前且未评分时允许更新或撤回；更新保留首次提交时间，记录最近更新时间。不选新附件时保留原附件。
5. 当前更新覆盖有效提交，不保留每次编辑的完整快照。历史版本主要用于保留旧系统重复提交数据。
6. 已评分、已截止、未开始、课程已归档、学生已退课时，不能更新或撤回。
7. 教师批改页面显示班级名单、未提交人数、待评分和已评分份数；已退课学生的提交另列并保留。

## 评分

- 课程教师可录入 0～100 的整数分数和评语；未评分与 0 分明确区分。
- 修改评分时追加记录，保留评分人、时间、分数及评语；学生可以查看最新成绩和历史记录。
- 旧系统已评分数据生成初始成绩记录。原评分人或时间未知时显示“未记录”，不会伪造原评分信息。
- 历史提交版本不能继续评分。退课学生的有效提交仍可评分；归档课程需恢复后才能评分。
- 本次未加入自动评分、退回重做或重新开放已评分提交。

## 附件与接口

- 作业和资料统一限制单文件最大 20 MB，拒绝空文件。
- 扩展名白名单：PDF、TXT、CSV、MD、DOC/DOCX、XLS/XLSX、PPT/PPTX、ZIP、PY、IPYNB、PNG、JPG/JPEG。
- 上传内容作为附件保存和下载，不执行 Python 文件或解压 ZIP；扩展名校验不等同于文件内容或病毒检测。
- 作业附件仅提交学生本人及课程教师可下载；课程资料仅本课程教师和选课学生可下载。
- 删除或替换附件后，在数据库事务提交后清理不再引用的文件；文件已经丢失时不阻止删除数据库记录。
- 原来的公共媒体文件路由已移除。若以后配置 Web 服务器，不应另外把私有 `media/` 作为公开目录提供。
- `/graphql/` 入口暂时关闭，旧 schema 文件保留。重新开放前必须统一身份、数据归属、文件和密码处理规则。
