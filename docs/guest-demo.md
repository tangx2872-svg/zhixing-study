# 访客演示模式

2026-10-06 已完成。启动平台后，从首页「访客体验 · 无需登录」或侧栏「访客演示」进入：

http://127.0.0.1:8000/research/demo/

## 展示内容

- 工业异常检测中的光照鲁棒性研究：4 位示例成员、6 项任务、7 次跨多天的科研进度；CSV v1/v2/v3、README v1/v2、数据检查和文献记录。
- 论文阅读与实验复现协作：4 位示例成员、4 项任务、4 次科研进度；文献清单 v1/v2、阅读笔记和复现计划。
- 所有项目支持概览、任务、进度搜索/筛选、进度详情、文件版本下载、成员进度和动态浏览。讨论内容包含示例导师建议。
- 任务包含已完成、不同进度的进行中任务；项目包含进行中和暂停两种状态。
- 所有成员、实验指标与文字均为展示样例，不代表真实科研结果。

## 访问与数据边界

演示内容复用现有科研模型、Resource 和文件存储，在同一数据库中通过只读的 demo_key 明确区分。普通项目默认标记为空，仍需登录和项目成员权限。项目创建/编辑表单不能设置公开演示标记。

公开浏览不创建登录会话、不自动加入项目。访客及登录账号都不能修改示例项目；服务器端同样拒绝上传、提交、评论和管理操作。示例账号禁用且密码不可用，不能用来登录系统。

只公开显式初始化的两个项目，详情和文件必须属于对应项目；修改地址中的任务、进度、文件或成员编号不能越界读取其他项目。直接 media URL 没有新增公开路由。

初始化只在管理命令中进行，GET 页面不写入示例数据。重复运行不覆盖原内容，也不重复创建文件版本。

## 部署与验证

本机已先备份并应用 research/0005（添加可空 demo_key），再准备示例数据。旧教学记录及附件迁移前后校验一致。其他副本可执行：

```powershell
conda activate classroom
python manage.py upgrade_research --apply
python manage.py seed_research_demo
python manage.py runserver
```

备份命令见主 README；如数据库不是 MySQL，先自行备份，再使用普通 `python manage.py migrate`。

验证：51 项回归测试 PASS，包括 4 项访客权限与示例初始化测试。浏览器匿名检查两个项目、六个项目页面、搜索、v1/v3 下载、私有项目登录限制；桌面 1440 px、手机 390 px 无横向溢出，未发现脚本异常或 HTTP 错误。
